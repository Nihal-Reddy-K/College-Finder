University Finder Web App

University Finder is a simple web application that allows users to search for universities by country and optionally filters the results by the mentioned state. It uses a public dataset of universities and displays results with links to their official websites. 

Link: https://nihal-reddy-k.github.io/College-Finder/

Features:
1. Search universities by country

2. Optional filtering by state/province

3. Sort results alphabetically (A–Z)

4. Dark mode toggle

5. Result counter and empty-state message

6. Country autocomplete suggestions

Tech Stack:
1. HTML

2. CSS

3. JavaScript 

4. Axios for data fetching
